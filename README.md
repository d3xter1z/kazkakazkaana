# DPKT meniu

MoonLoader scriptas (SA-MP) administravimui. Autorius: Dex.

- `dpmenu.lua` – pats scriptas (dėti į `moonloader` aplanką).
- `version.json` – dabartinė versija; pagal ją scriptas žaidime atsinaujina pats.
- `dpmenu_pakeitimai.md` – pakeitimų istorija.

Kaip išleisti naują versiją: pakeisti `script_version` ir įrašą „Pakeitimai“ skiltyje `dpmenu.lua`,
įkelti `dpmenu.lua` ir tada pakeisti `version.json` į tą pačią versiją.
